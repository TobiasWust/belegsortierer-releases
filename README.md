# Teichmann und Wust Belegablage – Downloads

Hier liegen die fertigen Installationsdateien der Teichmann und Wust Belegablage.

**[Zur neuesten Version](../../releases/latest)**

- **Windows:** `TeichmannWustBelegablage-Setup-x.y.z.exe` herunterladen und ausführen.
  Beim ersten Start meldet Windows „Der Computer wurde durch Windows geschützt“ –
  auf **Weitere Informationen** und dann **Trotzdem ausführen** klicken.
- **Mac (Apple Silicon):** `TeichmannWustBelegablage-x.y.z-mac-arm64.dmg` öffnen und das Programm in den
  Ordner „Programme“ ziehen. Beim ersten Start: Rechtsklick auf das Programm → **Öffnen**
  (oder Systemeinstellungen → Datenschutz & Sicherheit → **Dennoch öffnen**).

Das Programm arbeitet vollständig offline. Es fragt nur beim Start nach, ob es hier eine neuere Version gibt.
